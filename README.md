# Pharmacy Management System

## 📌 Project Overview
The Pharmacy Management System is a Java-based application developed to manage pharmacy and medicine details efficiently. It helps maintain medicine information, manage stock quantities, and calculate bills.

## 🎯 Objectives
- To store and manage pharmacy details.
- To maintain medicine information and stock.
- To simplify billing calculations.
- To identify medicines with low stock.
- To reduce manual work and improve accuracy.

## 🛠️ Technologies Used
- **Programming Language:** Java
- **IDE:** Visual Studio Code
- **Version Control:** Git and GitHub

## ✨ Features
- Pharmacy details management
- Medicine details management
- Medicine stock monitoring
- Bill generation and total amount calculation
- Low-stock identification

## ▶️ How to Run the Project

1. Install the Java Development Kit (JDK).
2. Open the project folder in Visual Studio Code.
3. Compile the Java files:
   ```bash
   javac Pharmacy.java Main.java
   ```
4. Run the program:
   ```bash
   java Main
   ```

*Note: Adjust the compilation command if your source files use Java packages or are stored in different folders.*
